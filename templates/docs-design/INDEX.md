# Design record index

The design source-of-truth index (framework Part 5c): what is locked, from
which canvas, what each redline governs, and which spec consumed it. The
design surface is Claude Code's `/design`: an intake drafts artboards on a
canvas on claude.ai, and the human picks one per screen. A design decision
that is not committed here does not exist, and the canvas is not the record.

Every intake ends with the export step, before the spec that builds to it
goes ACTIVE: commit the redline (numbered decisions with exact values, its
header naming the artifact's title, address, the version locked and the
date), each picked artboard exported as PNG or PDF from the canvas page in a
desktop browser, the picked boards' source as a read of the artifact saves it,
every decision a comment thread records, and this table's rows.
